# Bullish Breakout Screener - Deployment Guide

## Overview

The Bullish Breakout Screener is a fully functional web application that uses AirTable as the backend database and provides Google OAuth authentication through Manus. The application analyzes stocks using 5 technical indicators to identify bullish breakout opportunities.

## Architecture

**Frontend:** React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui  
**Backend:** Node.js + Express + tRPC 11  
**Database:** AirTable (4 tables: Users, Portfolios, Stocks, Stock Analysis)  
**Authentication:** Manus OAuth (Google Sign-In)  
**Market Data:** Yahoo Finance API

### Creating Tables in AirTable

**Option 1: Use AirTable AI Agent**

Copy and paste the field specifications above into AirTable's AI agent to automatically create the tables.

**Option 2: Manual Creation**

1. Create a new base in AirTable called "Bullish Breakout Screener"
2. Create each table and add fields according to the specifications above
3. Set up linked record relationships between tables
4. Configure field types and formats as specified

### Personal Access Token (PAT)

1. Go to https://airtable.com/create/tokens
2. Click "Create new token"
3. Name it "Bullish Screener API"
4. Add the following scopes:
   - `data.records:read` - See the data in records
   - `data.records:write` - Create, edit, and delete records
   - `schema.bases:read` - See the structure of a base
5. Under "Access", add your "Bullish Breakout Screener" base
6. Click "Create token" and copy the token

## Deployment to B12.io

### Prerequisites

1. **AirTable Base** set up with all 4 tables
2. **AirTable Personal Access Token** with proper permissions
3. **AirTable Base ID** (starts with "app...")

### Deployment Steps

#### 1. Export Project from Manus

After creating a checkpoint in Manus, click the "Publish" button in the Management UI to deploy the application.

#### 2. Configure B12.io

1. Create a new site on B12.io
2. Connect your Git repository (if using Git deployment)
3. Configure build settings:
   - **Build Command:** `pnpm install && pnpm build`
   - **Output Directory:** `dist`
   - **Node Version:** 22.x

#### 3. Set Environment Variables in B12.io

In your B12.io project settings, add the following environment variables:

```
AIRTABLE_API_KEY=your_pat_token
AIRTABLE_BASE_ID=your_base_id
```

#### 4. Deploy

Push your code or trigger a deployment in B12.io. The platform will:
- Install dependencies
- Build the frontend
- Start the Node.js server
- Make the application available at your B12.io URL

### Alternative Deployment (Direct Upload)

If B12.io supports direct file upload:

1. Download all project files from Manus
2. Upload to B12.io via their dashboard
3. Configure environment variables
4. Deploy

### Technical Indicators

The screener analyzes stocks using 5 technical indicators:

1. **Simple Moving Averages (SMA)** - Score: 0-25
   - Tracks 10, 50, and 200-day moving averages
   - Detects golden crosses (bullish signal)
   - Identifies trend strength

2. **MACD (Moving Average Convergence Divergence)** - Score: 0-20
   - Analyzes MACD line vs signal line crossovers
   - Detects momentum shifts
   - Identifies bullish divergences

3. **RSI (Relative Strength Index)** - Score: 0-20
   - Identifies oversold conditions (RSI < 30)
   - Detects bullish momentum (RSI 50-70)
   - Flags overbought conditions

4. **Volume Analysis** - Score: 0-15
   - Compares current volume to 50-day average
   - Detects volume surges (2x, 3x, 5x average)
   - Signals institutional interest

5. **52-Week High Breakout** - Score: 0-15
   - Tracks proximity to 52-week high
   - Detects breakout patterns
   - Identifies strong momentum stocks

### Scoring System

- **Total Score:** 0-100 (sum of all indicator scores)
- **Recommendations:**
  - **STRONG BUY:** Score ≥ 75
  - **BUY:** Score 60-74
  - **WATCH:** Score 45-59
  - **PASS:** Score < 45

## User Guide

### Getting Started

1. **Sign In:** Click "Sign In with Google" on the landing page
2. **Create Portfolio:** Click "Create Portfolio" and enter a name
3. **Add Stocks:** Open your portfolio and click "Add Stock"
4. **Run Screener:** Click "Run Screener" to analyze all stocks
5. **View Results:** See detailed analysis with scores and recommendations

### Adding Stocks

1. Click "Add Stock" in your portfolio
2. Search by ticker symbol or company name
3. Select the stock from search results
4. Click "Add Stock" to confirm

### Running the Screener

1. Ensure your portfolio has at least one stock
2. Click "Run Screener" button
3. Wait for analysis to complete (typically 10-30 seconds)
4. View results sorted by total score

### Understanding Results

Each stock analysis shows:
- **Total Score:** Aggregate score from all indicators
- **Recommendation:** STRONG BUY, BUY, WATCH, or PASS
- **Price Info:** Current price and daily change
- **Indicator Scores:** Breakdown of each technical indicator
- **Alerts:** Special conditions (e.g., GOLDEN_CROSS, VOLUME_SURGE_3X)

## Troubleshooting

### AirTable Connection Issues

**Error:** "An API key is required to connect to Airtable"

**Solution:** Ensure `AIRTABLE_API_KEY` environment variable is set with your Personal Access Token.

**Error:** "You are not authorized to perform this operation" (403)

**Solution:** 
1. Check that your PAT has the correct scopes
2. Verify the base is added to the token's access list
3. Ensure all tables are accessible by the token

### Authentication Issues

**Error:** User not redirected after Google sign-in

**Solution:** Verify OAuth configuration in Manus platform settings.

### Screener Not Running

**Error:** "Portfolio has no stocks"

**Solution:** Add at least one stock to the portfolio before running the screener.

**Error:** "Invalid stock symbol"

**Solution:** Ensure you're using valid ticker symbols (e.g., AAPL, MSFT, GOOGL).

## API Documentation

### tRPC Endpoints

The application exposes the following tRPC procedures:

#### Authentication
- `auth.me` - Get current user
- `auth.logout` - Logout current user
- `auth.syncUser` - Sync user with AirTable

#### Portfolios
- `portfolios.list` - Get all user portfolios
- `portfolios.create` - Create new portfolio
- `portfolios.update` - Update portfolio details
- `portfolios.delete` - Delete portfolio
- `portfolios.addStock` - Add stock to portfolio
- `portfolios.removeStock` - Remove stock from portfolio

#### Screener
- `screener.getResults` - Get analysis results for portfolio
- `screener.getTopOpportunities` - Get top-scored stocks
- `screener.runScreener` - Run analysis on portfolio stocks
- `screener.searchStocks` - Search for stocks by symbol/name
